# Topics

One folder per topic area, numbered in stage order because the stages are a sequence. Each
README has the same sections: Scope, Questions, What we know, Sources, Method, Tasks, Open
questions. "What we know" cites finding ids from `research/findings/findings_ledger.csv`.

| Folder | Layer | Status |
|---|---|---|
| `01_clinical_stage` | First-in-human to approval | data in hand |
| `02_access_stage` | Approval to reimbursement | new |
| `03_uptake_stage` | Reimbursement to patients treated | new |
| `04_investment` | Sponsor commitment and capital | new, partly from existing data |
| `05_projection` | Frontier timelines under scenarios | new |
| `06_diagnostics` | Coverage and uptake of molecular diagnostics | new, uses existing assay-as-intervention counts |
| `07_companion_methods_paper` | What the registry stated-reason field can and cannot show | manuscript v7 in hand |
